# Used Car Price Prediction – Turbo.az Dataset

## Overview
This project builds a machine learning model to predict used car prices using real listing data.

## Technologies
Python
Pandas
Scikit-learn
NumPy
Matplotlib

## Machine Learning Model
GradientBoostingRegressor

## Steps
1. Data cleaning
2. Feature engineering
3. Pipeline preprocessing
4. Model training
5. Model evaluation
6. Visualization

## Model Results
R2 Score: ~0.78
MAE: ~3200 AZN

## Dataset
Turbo.az dataset from Kaggle
